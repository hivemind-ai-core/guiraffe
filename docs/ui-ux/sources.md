# Research notes

Sources consulted on 17 November 2026. This is a practical synthesis for native desktop work. Treat platform conventions, accessibility criteria, practitioner heuristics and empirical UX measures according to the type of evidence each provides.

| Source | Application |
|---|---|
| Local Refactoring UI v1.0.2 book and Component Gallery v1.1.0 | Visual hierarchy, spacing systems, type roles, palette roles, surface depth and component states. Adapt composition decisions to native controls and preserve accessible labels. [Publisher](https://www.refactoringui.com/) |
| GNOME HIG and Microsoft Windows design guidelines | Native navigation and controls, input conventions, adaptive layouts and visual foundations. [GNOME](https://developer.gnome.org/hig/) · [Microsoft](https://learn.microsoft.com/en-us/windows/apps/design/guidelines-overview) |
| Nielsen's usability heuristics | Expert review prompts for visibility, control, error prevention, recovery and discoverability. Check inferred issues in representative tasks. [Original author](https://www.nngroup.com/articles/ten-usability-heuristics/) |
| W3C WCAG 2.2, WCAG2ICT and WAI APG | Contrast and interaction reference criteria, interpretation for non-web software, and keyboard conventions for composites. APG web markup examples inform behavior while GPUI supplies the native implementation. [WCAG 2.2](https://www.w3.org/TR/WCAG22/) · [WCAG2ICT](https://www.w3.org/TR/wcag2ict-22/) · [APG](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/) |
| GOV.UK Service Manual | Research planning, inclusive recruitment, observation and moderated testing. [User research](https://www.gov.uk/service-manual/user-research) |
| Design Council and NN/G information architecture methods | Connect discovery to prototype validation and test the labels and grouping of navigation. [Framework](https://www.designcouncil.org.uk/resources/framework-for-innovation) · [Card sorting and tree testing](https://www.nngroup.com/articles/card-sorting-tree-testing-differences/) |
| Rodden, Hutchinson and Fu, Google HEART | Translate a user outcome into observable signals and metrics. Adapt measurement to desktop workflows and privacy constraints. [Original paper](https://research.google/pubs/measuring-the-user-experience-on-a-large-scale-user-centered-metrics-for-web-applications/) |
| Design Tokens Community Group 2025.10 | Optional interchange model for tooling with a demonstrated need. [Format report](https://www.designtokens.org/tr/2025.10/format/) |

Local bundle use focused on the written book and representative component examples. The videos, asset sets and palette and font catalogs were outside the review. The framework recommendations come from inspection of the release revision and require runtime and user validation during implementation.
