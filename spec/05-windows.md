# guiraffe-windows
Rock-solid multi-window: typed `WindowRegistry` (id → handle, kind, title), open/focus/close-or-reuse singleton windows, parent/child & modal windows, cross-window event bus (typed, no leaks after close), state persistence (size/pos/maximized per kind, restore on startup, clamp to visible displays), graceful close-request vetoing (unsaved changes), quit when last window closes policy, tear-off panels between windows (see ../gui/research/docks). Must survive: closing windows during event dispatch, rapid open/close, display disconnect. Exhaustive tests with TestAppContext.
