# GUIraffe cache audit

Base: `1e9d2367a3541a8eb05cc8588de46c63f97972a0` on `perf-cache-audit`. Static source review against [spec/23](../spec/23-production-readiness.md). Test names identify existing source evidence. The base inventory describes the static review. The findings and affected rows below include dispatch follow-up.

## Findings in risk order

1. **High · Sheet recalculation.** The empty mailbox takes the submitted vector in constant time. Later batches coalesce to an overlay with one value per touched cell, and the worker skips overridden base inputs. A worker can own one applying batch. One unread snapshot is retained. `a_running_formula_is_superseded_off_thread` reproduced 10,001 references to a test payload (including the fixture) before the fix. `unread_calculation_churn_retains_latest_publication_only` covers consecutive unread revisions. `initial_submit_allocations_are_independent_of_batch_size` and the [release probe](../crates/sheet/PRODUCTION.md#release-scale-sheet-probe) verify the constant-time handoff.
2. **High · Notification overflow.** Pending cards are outstanding app data and remain FIFO with no count cap. Dismiss releases queued payloads and handlers, clear drops queue storage, and teardown releases the owner. The visible limits apply only to visible cards. `overflow_toasts_survive_admission_and_release_on_dismiss_or_clear` and `overflow_notifications_release_callbacks_and_payloads_on_dismiss_and_clear` cover both queues. `notification_owner_teardown_releases_queued_handlers` and `window_close_releases_toasts_even_when_host_handle_survives` verify teardown release.
3. **High · Code decoration styles.** Final layer reference removal releases the style and its lookup entries. The old key resolves to no style, and subsequent interning gets a fresh key. Never-used styles remain staging data for the set's lifetime. Covered by `style_churn_releases_payloads_without_reusing_keys`.
4. **High · Chat pins.** Fully ended reply rows now enter ordinary cache eviction even without an intervening render. One producer is active per chat. The selection exception remains open. `superseded_offscreen_replies_respect_the_row_cache` and `selection_retention_across_one_hundred_thousand_rows` exercise the two paths.
5. **Medium · Tray ingress.** Scroll bursts coalesce by axis between ordered events. Activations and host transitions remain lossless and can accumulate as pending user input. Removal and receiver teardown release the queue. `scroll_churn_coalesces_and_activation_order_survives_until_teardown` covers 100,000 inputs per axis and ordered events.
6. **Medium · Named persistence.** `WindowManager::forget_saved_layout` explicitly deletes a saved record. Open windows can record bounds again. `forgotten_window_layouts_do_not_return_after_reload` checks persisted removal. Splitter and overlay context removal are covered by the earlier inventory fix.
7. **Medium · Presence and vendored frame scratch.** Presence shrinks oversized storage when exits settle, covered by `presence_churn_releases_settled_exit_capacity`. **OPEN.** Vendored frame state, access logs and tab-stop backing buffers retain historical peaks in each alternating frame. `alternating_frames_retain_peak_storage` measures both buffers. The [frame probe report](../PRODUCTION.md#frame-storage-retention-probe) records the retained bytes. The foreman approved deferring the trim implementation.
8. **Medium · Weak trace observers.** Registration prunes after growth to twice the population after the last sweep (at least 32), and notification still prunes immediately. `dead_trace_registration_churn_is_pruned_without_scanning_every_push` checks retained entries and total liveness probes. Tray mock recording remains test-owned.
9. **Medium · Store debounce.** A superseding keyed dispatch releases the previous payload synchronously. The current action is owned by the store until delivery, replacement or teardown. `debounce_churn_releases_superseded_actions_immediately` observes action references before any timer deadline.
10. **Medium · SNI updates.** One flush owns the platform update and loops over one replaceable pending slot. The slot check and transfer to idle are atomic with staging. `sni_updates_keep_one_flush_owner_and_the_final_snapshot` covers staging before connection, while flushing and after idle.

The added sections cover Sheet, Tray, Components, motion and tree collapse, and vendored patches. The old summary's universal bound claim misses Sheet's two queues, native tray ingress, window notification overflow, persisted window layouts, caller-visible style IDs, and historical GPUI frame capacity. The old inventory does contain useful lower-level rows for several workspace models. A documented entry count is distinct from a byte cap and tests of normal replacement are distinct from tests of adversarial growth.
